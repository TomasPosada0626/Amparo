# Amparo
Amparo un asistente jurídico basado en IA que utiliza LLMs y RAG para responder consultas legales, analizar documentos y ofrecer información fundamentada en fuentes verificadas. El proyecto aplica buenas prácticas de ingeniería de software, arquitectura escalable, seguridad, pruebas, APIs REST y DevOps, simulando un entorno de producción LegalTech.
